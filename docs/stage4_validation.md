**Agreement with the independent implementation (statsmodels): YES.** The project code and statsmodels use the same textbook formulas and are written independently; they are compared with and without the small-sample correction. linearmodels absorbs the fixed effects and applies its own degrees-of-freedom convention, so its standard error is shown for reference and is not expected to match to the last digit.
